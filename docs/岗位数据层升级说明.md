# 岗位数据层升级说明

Generated: 2026-06-05 (updated 2026-06-06)

## 当前结论

原始岗位库只有 `data/jobs.json` 的 20 条内置岗位，不足以支撑"岗位知识库"这个说法。现在已扩展：

- `data/jobs_corpus.json`: **500 条**（HF 公开数据 452 条 + curated_seed 48 条）
- `data/jobs_merged.json`: **500 条**，保留旧文件名兼容 App
- `data/job_corpus_stats.json`: 数据统计报告
- `reports/job_corpus_analysis.md`: 数据质量分析报告（由 `scripts/analyze_job_corpus.py` 生成）
- `reports/corpus_eval_report.md`: 大库检索质量评估报告（由 `scripts/eval_corpus_quality.py` 生成）

App 中"内置+公开合并 (merged)"模式会优先读取 `data/jobs_corpus.json`。

**重要说明**：
- `curated_seed` 是离线覆盖库，不能冒充真实爬取数据
- 真实公开数据已通过 Hugging Face Dataset Viewer API 接入（452 条）
- 数据来源：`Sundaydream/tech-jobs-dataset-2026`（296 条）、`batuhanmtl/job-skill-set`（145 条）、`arjun10g/na-tech-jobs`（11 条）

## 数据来源

| 来源 | 数量 | 说明 |
|---|---:|---|
| 内置岗位 `jobs.json` | 20 | 手工高质量 golden/demo 岗位，用于稳定 Eval |
| Hugging Face 公开数据 | 452 | `Sundaydream/tech-jobs-dataset-2026`、`batuhanmtl/job-skill-set`、`arjun10g/na-tech-jobs` |
| `curated_seed` | 48 | 离线方向覆盖库，用于覆盖 LLM、Agent、推荐、搜索、NLP、CV、后端、数据分析、ML 平台等方向 |

说明：`curated_seed` 不是实时爬取的真实 JD，不能在汇报里冒充真实数据。它的作用是让 Demo 在无网络环境下具备更完整的岗位方向覆盖。
Hugging Face 数据通过 Dataset Viewer API 获取，属于真实的公开技术岗位数据。

## 计划接入的公开数据源

脚本 `scripts/build_job_corpus.py` 已预留 Hugging Face Dataset Viewer API 接入，网络恢复后可以运行：

```powershell
python scripts\build_job_corpus.py --target-size 500 --try-hf --hf-limit-per-source 300
```

候选公开源：

- `Sundaydream/tech-jobs-dataset-2026`: 技术岗位数据，约 1020 条，字段含 title/company/location/employment_type/description
- `batuhanmtl/job-skill-set`: job title / job description / job skill set
- `arjun10g/na-tech-jobs`: 北美技术岗位，字段含 role family、seniority、tech stack、description

今晚本机访问 Hugging Face datasets-server 出现 SSL 握手失败，所以没有强行把失败网络请求写入正式数据。
