# 公网部署说明

## 推荐方案：3060 + Ngrok（零配置公网暴露）

### 前置：3060 Streamlit 启动

```powershell
# SSH 到 3060
cd D:\Pycharm_workplace\offer_catcher_agent_demo_20260602
streamlit run app.py --server.address 127.0.0.1 --server.port 8502 --server.headless true
```

### 健康检查（确认启动成功）

```powershell
powershell -NoProfile -Command "$resp=Invoke-WebRequest -Uri http://127.0.0.1:8502/_stcore/health -UseBasicParsing; Write-Output $resp.Content"
# 输出: ok
```

### Ngrok 公网暴露

```bash
# 在 3060 上下载 ngrok（一次性）
# 下载 Windows 版: https://ngrok.com/download
# 或通过 winget: winget install ngrok

# 暴露端口
ngrok http 8502
```

Ngrok 启动后会输出公网 URL，类似：`https://xxxx.ngrok-free.app`

### 提交时填写

将 Ngrok 输出的 URL（如 `https://xxxx.ngrok-free.app`）填入提交表单。

### 备选方案

- **CloudStudio**：本地 `workbuddy_cloudstudio_deploy --directory ./ --port 8502`
- **Streamlit Cloud**：推送到 GitHub，在 share.streamlit.io 部署
- **直接 3060 IP**：如果 3060 有公网 IP，在防火墙放行 8502 端口后直接用 `http://<IP>:8502`

## 常见问题

| 问题 | 解决 |
|------|------|
| 端口占用 | `netstat -ano | findstr 8502` 查进程，`taskkill /PID <pid> /F` 杀掉 |
| 防火墙拦截 | 控制面板→防火墙→入站规则→新建规则→端口 8502→允许 |
| health ok 但外网打不开 | 检查是否用了 127.0.0.1（仅本机），改用 `--server.address 0.0.0.0` |
| ngrok 报 TLS 错误 | 添加 `--host-header=rewrite` 参数 |
| Streamlit 突然挂掉 | `start-process` 后台运行或搭配 `nssm` 注册为 Windows 服务 |
