# Offer 捕手 — 比赛提交公网部署步骤

目标：生成一个**长期可访问的公网 Demo 链接**，用于腾讯 AI-HR 实战营作业提交。

**禁止作为最终提交链接**：
- ❌ 127.0.0.1
- ❌ 10.x.x.x / 192.168.x.x 内网 IP
- ❌ 100.x.x.x Tailscale IP
- ❌ SSH 隧道
- ❌ 临时隧道链接

**推荐方案**：Hugging Face Docker Space（公网 URL 稳定，适合比赛提交）

---

## 一、准备工作

### 1. 注册 Hugging Face 账号

打开 https://huggingface.co/join 注册账号。

### 2. 确认部署资产齐全

以下文件必须存在且内容正确：

| 文件 | 说明 |
|------|------|
| `Dockerfile` | 使用 Python 3.11 slim，监听 7860 端口 |
| `requirements-public.txt` | 公网版依赖（streamlit, sentence-transformers, faiss-cpu 等） |
| `.dockerignore` | 排除 .env、*.log、本地隧道工具等敏感/临时文件 |
| `README.md` | 必须包含 HF Space metadata（`sdk: docker`） |
| `app.py` | Streamlit 主入口 |
| `src/` | 所有源码 |
| `data/` | 岗位库 |
| `prompts/` | Prompt 模板 |
| `eval/` | Eval 框架 |
| `reports/` | 评估报告 |

✅ 本项目已准备好所有资产，无需修改。

---

## 二、创建 Hugging Face Space

### 1. 打开创建页面

打开 https://huggingface.co/spaces  → 点击 **"Create new Space"**

### 2. 填写 Space 信息

| 字段 | 值 |
|------|-----|
| **Space name** | `offer-catcher-agent`（或你喜欢的名字） |
| **SDK** | **Docker**（重要！不要选 Streamlit） |
| **Visibility** | 建议先选 **Public**（方便评委访问） |
| **License** | MIT |

点击 **"Create Space"**。

### 3. 获取仓库 URL

创建后会跳转到 Space 页面，URL 类似：
```
https://huggingface.co/spaces/<你的用户名>/offer-catcher-agent
```

记下这个 URL，后面提交比赛时会用到。

---

## 三、上传文件到 Space

### 方法 1：网页上传（推荐，简单）

1. 打开你的 Space 页面
2. 点击 **"Files"** 标签
3. 点击 **"Add file"** → **"Upload files"**
4. 上传以下文件/文件夹：

**必须上传**：
```
Dockerfile
requirements-public.txt
README.md
app.py
src/          （整个文件夹）
data/         （整个文件夹）
prompts/      （整个文件夹）
eval/         （整个文件夹）
reports/      （整个文件夹）
```

**不要上传**：
```
.env
.env.example
*.log
本地隧道工具
streamlit_3060_tunnel.*.log
.workbuddy/
```

5. 点击 **"Commit changes to main"**

### 方法 2：Git 克隆推送（适合批量上传）

```bash
# 1. 克隆 Space 仓库
git clone https://huggingface.co/spaces/<你的用户名>/offer-catcher-agent
cd offer-catcher-agent

# 2. 复制文件到仓库
cp -r /path/to/Offer\ 捕手：基于\ LLM\ Agent\ 的学生岗位匹配与简历优化系统/* .

# 3. 删除不应该上传的文件
rm -f .env .env.example *.log
rm -rf .workbuddy/

# 4. 提交并推送
git add .
git commit -m "Initial commit: Offer Catcher Agent"
git push
```

## 四、配置 API Key（可选）

Demo **无 API Key 也能完整运行规则版流程**。若要启用 LLM 解析增强：

1. 打开你的 Space 页面
2. 点击 **"Settings"** → **"Variables and secrets"**
3. 点击 **"New secret"**
4. 添加以下 Secrets（**不要写在代码里**）：

| 变量名 | 值 |
|--------|-----|
| `LLM_PROVIDER` | `deepseek` |
| `LLM_API_KEY` | 在 Hugging Face Space Secrets 中填写，不能写入仓库 |
| `LLM_BASE_URL` | `https://api.deepseek.com/v1` |
| `LLM_MODEL` | `deepseek-chat` |

没有 Key 时，系统会自动 fallback 到规则版解析。

## 五、等待 Build 完成

上传文件后，Hugging Face 会自动开始 Build：

1. 打开你的 Space 页面
2. 点击 **"Logs"** 标签查看构建进度
3. 等待出现绿色 **"Running"** 状态

Build 时间通常 5-10 分钟（需要下载依赖和预缓存语义模型）。

## 六、验收标准

Space Build 完成后，打开公网链接并检查：

| 验收项 | 如何检查 |
|--------|----------|
| ✅ 首页能打开 | 访问 `https://<你的用户名>-offer-catcher-agent.hf.space`，能看到 Streamlit UI |
| ✅ 粘贴简历后能生成岗位推荐 | 在文本框粘贴简历文本，点击"开始匹配"，能看到推荐列表 |
| ✅ 岗位详情能展开证据链 | 点击某个岗位，能看到 Match/Priority/Action 的详细评分和证据 |
| ✅ Eval 面板能展示指标 | 展开 Eval 诊断面板，能看到 Core/Stress 测试结果 |
| ✅ 语义召回面板不报错 | 展开"语义召回证据"标签页，能看到规则 Top5 vs 语义 Top5 对比 |

## 八、常见问题

### Q1: Build 失败怎么办？

打开 Space 的 "Logs" 标签查看错误信息：
- 如果是依赖安装失败，检查 `requirements-public.txt` 格式
- 如果是端口问题，确认 Dockerfile 中 Streamlit 监听 `7860` 端口
- 如果是语义模型下载失败，检查网络或更换模型

### Q2: 如何更新 Demo？

重新上传文件到 Space 仓库，Hugging Face 会自动重新 Build。

### Q3: 如何临时维护？

在 Space 的 "Settings" 中可以暂停（Pause）或删除 Space。

### Q4: 没有 Hugging Face 账号怎么办？

备选方案：
1. **Streamlit Community Cloud**（需要 GitHub 仓库）
2. **阿里云/腾讯云轻量应用服务器**（需要自己配置 Docker）
3. **Railway / Render**（有免费额度）

但不如 Hugging Face Space 稳定和简单。
